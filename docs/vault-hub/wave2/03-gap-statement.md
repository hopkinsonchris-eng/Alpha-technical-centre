# Wave 2 — Gap Statement

Nobody currently ships a firm-scale evaluation workspace where **the map is the
index, the opportunity is the container, and every tool opens already inside
it**. The data platforms (Wood Mackenzie Lens, Rystad UCube) are map-first but
they hold the vendor's data, not the firm's own runs, letters and lessons; the
matter-centric systems (iManage, Salesforce) hold the firm's own record but
start from a list, not a map, and their "tools" are documents, not
calculators; the context-following standard (CCOW) exists only in hospitals.
The evidence is the Practice Scan: each of P13–P21 is done well somewhere, none
of them together, and none on top of an immutable, scope-gated, cited run
store like the one shipped yesterday. Doing it here would win the thing a
five-person consultancy cannot buy: a partner opens the Hub, sees the planet
with the firm's footprint on it, touches Kazakhstan, and is two taps from the
last waterflood screen, the letter that quoted it, the lesson learned from
it, and the nodal-analysis tool already pointed at that project. Falsifiable
test: after this wave an associate who has never used the Hub can, from the
front page and without typing an id, reach a named project's latest run and
open a tool in that project in under 30 seconds on an iPad.
