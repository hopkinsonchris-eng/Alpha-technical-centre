# Wave 3 — Gap Statement

Nobody currently closes the loop from a tap on a map to a documented, located field in a
confidential project file without a person retyping anything. The data platforms (Wood
Mackenzie Lens, Rystad) hold a located hierarchy but of the vendor's assets, not ours, and
they never read our documents; the industrial contextualisation tools (Cognite) read documents
and propose links to assets, but only within an engineering data model the operator already
owns, and know nothing of public gazetteers or country risk; the public trackers (Global
Energy Monitor, GeoNames, Wikidata) locate fields but link to no one's project. The evidence
is the Practice Scan: P23–P29 each exist, none together, and none on top of a scope-gated
store that already holds the firm's runs, letters and lessons. Doing it here would win the
thing the first live day asked for: tap Venezuela, say yes to a project, drop in a data-room
index, and watch the fields it names appear as proposals with the sentence that names each,
a located pin and a dossier, with every fact citing its source. Falsifiable test: after this
wave, uploading a document that names three producing fields to a fresh project yields three
proposals within a minute of indexing, each with a location candidate from a named gazetteer,
and accepting one files a cited dossier and puts the field on the globe.
