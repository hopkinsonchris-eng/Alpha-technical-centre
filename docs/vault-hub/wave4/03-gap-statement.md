# Wave 4 — Gap Statement

Nobody currently turns a one-line opportunity ("High Tech Electronica, Venezuela, fields X and Y") into a cited, project-scoped research file without a person running the searches by hand. The subscription platforms (World Monitor, Bloomberg, Wood Mackenzie) answer per entity but file nothing into the firm's own record, and their answers cannot be cited by the firm's drafting assistant; the Vault's miners file cited records but only for the firm's standing topics on a weekly timer, not for a project's own fields and operators the moment they are named. The evidence is Chris's first session: two fields attached, a country selected, a World Monitor licence paid for, and the project file still empty of anything the Vault could have found by itself. Doing it (a budgeted research run per project that queries the paid feeds and the miners with the project's own names, files every finding as a cited public note under the project, and opens proposals for the fields, operators and figures it names) would win the thing the firm sells: a partner opening a project file on Monday morning finds the Vault already read everything the firm has access to about it, with every sentence traceable.
