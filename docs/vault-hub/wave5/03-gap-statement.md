# Wave 5 — Gap Statement

Nobody currently gives a small technical consultancy one place that stores every file, run, draft, finding and lesson under confidentiality rules, lets a partner look at the original and write from the whole file on an iPad, and lets the same memory stand behind every conversation with a general assistant. The evidence: legal and data-room products (iManage, Datasite, Harvey) do the viewing and the cited drafting but are built for firms with a hundred users and keep the memory inside their own product; the assistant products (Claude Projects, NotebookLM) remember only what was uploaded to them by hand, so a document they write has to be uploaded back before the next one knows it exists, which is exactly the failure Chris described. The Vault already holds the memory and the drafter; what is missing is the three doors (see the original, write from the file, connect the assistant) and a durable store behind them. Doing this would win the thing the firm set out to build: a project file that loads everything, finds everything, remembers everything and is the same memory whether you open the Hub or the Claude app.
