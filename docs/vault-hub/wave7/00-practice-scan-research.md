# Wave 7 — Practice Scan research: an indispensable Hub

Tooler phase 1 research, 5 October 2026. Brief from Chris Hopkinson: make the Hub indispensable. Four strands: quality (every screen works, nothing stale), clarity (a UI senior engineers find obvious and visually impactful), a data hierarchy that flows the way petroleum engineers think with the important data to the fore, and step-change functionality, first of all an automatic country opening pack (hydrocarbon law, licence rounds and their process, operators active, service-industry status, fiscal terms, regulator, data rooms) when a project opens in a new country. This file is the research input to the Practice Scan; the scan itself, the choice sheet and the gap statement follow it.

## What the code says before any practice is adopted

- **A country already has a panel, a brief and a risk line, but no pack.** `GET /api/countries` (`vault/src/api/countries.routes.ts`) groups visible projects by country with attention flags (stale runs, filing queue, expiring legal tags) and World Monitor's composite risk. "Brief this country" (`vault/src/llm/brief.ts`) assembles the Vault's own runs, documents and lessons for the country, adds live risk, and asks the provider for cited paragraphs; it cannot say anything the Vault does not already hold. Nothing fetches a regulator, a law, a licence round or a fiscal regime.
- **The research runner is the natural engine for a pack.** A wave 4 research run (`vault/src/research/run.ts`) builds queries from the project's names, asks the gazetteers, the GEM wiki, World Monitor, the web search tool and the literature miners, files every finding as a cited public note with URL, date, query and verbatim excerpt (`findings.ts: fileFinding`), reads operator, licence and production facts out of findings as proposals, and stops at 15 minutes or about £3. It is per project, not per country, and its sources are news and literature, not regulators.
- **Citation enforcement is already the rule.** Drafts, briefs and research facts each carry `[run:]`/`[doc:]` or a URL; the provider is told to cite or stay silent; `readFacts` returns a quote with every value. A country pack built on the same path inherits the rule for free, and so inherits its consequence: a section with no reachable source stays empty.
- **Staleness is per record, not per source.** `vault/src/jobs/staleness.ts` marks runs stale by rule (inputs superseded, cited runs stale) and items stale when a citation is stale; `nightly-staleness.ts` runs it. Nothing records that a *source* (a regulator dataset, a rig count, a land map) has a cadence and has been missed, so a country fact filed in March is not flagged in October even when the regulator republished in July.
- **The hierarchy stops at Field.** Country → Project → Field exists (projects with country and coordinates; assets with location and source). Organisations exist as rows and as operator proposals, but there is no Licence, no Round and no Regulator object, so "operators active in this country" is derivable only by reading project files one by one.
- **The Hub is static pages on one `style.css`, used from iPads.** `hub/index.html` (Today, globe), `project.html`, `queue.html`, `search.html`, `settings.html`, `tool.html`, `analogues.html`, `cost.html`. There is no country page, only the country panel on the globe. There is no saved view, no column template and no compare view on the register.
- **Tools declare their inputs in `tools/<id>/hub.json`** and open with `?project=<id>`. A pack that stores fiscal terms as structured fields could feed them to the economics calculators through that sidecar without a new mechanism.

## Hard constraints that bind the choices

- **NSTA.** Catalogue is DCAT at `open-data-ukcs-transition.hub.arcgis.com/data.json` (733 datasets on 5 Oct 2026, harvested by data.gov.uk as "nsta open data", 452 datasets listed there on 18 June 2026); each dataset exposes ArcGIS GeoServices REST, CSV, GeoJSON, KML, ZIP; licence datasets modified daily. Terms are the NSTA User Agreement (June 2023 PDF, read): a "free, perpetual, non-exclusive right" to "copy, publish, distribute and transmit", "adapt" and "exploit… commercially and non-commercially", on condition of the attribution "Contains information provided by the North Sea Transition Authority and/or other third parties"; excludes personal data, logos and third-party rights; "as is", no guarantee of continued supply. No API key and no stated rate limit; the NDR (ndr.nstauthority.co.uk) is a separate portal with its own API and is not open data.
- **Sokkeldirektoratet.** NLOD 1.0 on FactPages and FactMaps, with the caveat that "reports, core images and logs etc." may carry third-party rights; daily synchronisation (timestamp on every page); licence table exports Excel, CSV and XML with all rows; FactMaps WFS at `factmaps.sodir.no/api/services/Factmaps/FactMapsED50UTM32/MapServer/WFSServer`. The technical-information page sits behind a Cloudflare JavaScript challenge, so a server-side fetcher must use the table export and WFS endpoints, not that page. Transactions after a licence's expiry do not appear.
- **ANH Colombia.** FeatureServer with `maxRecordCount` 2,000 (page the query), spatial reference 3116 (reproject to WGS84 for the globe), GeoJSON supported, attachments present; the base map is credited to IGAC and the page links a copyright and authorisation PDF that was not read, so reuse terms are unverified until it is; the published land map is dated 27 Nov 2024 while the service layer is dated 2025-02-14 and a newer "Tierras 2026-08-06" layer exists, so the pack must record which it used.
- **Argentina.** CKAN at `datos.energia.gob.ar/api/3/action/package_show` answers only over plain HTTP (HTTPS redirects back to HTTP), which Render's fetch must allow explicitly; licence CC-BY-4.0; SHP and CSV; concessions modified 1 Oct 2026; production by well monthly.
- **ANP Brazil.** Round data as CSV (blocks offered, winning offers, rounds 9 to 17, updated 6 March 2026; contract assignments 2001 to 2026, updated 1 July 2026); no licence statement on the page, published through dados.gov.br; the technical data package is behind e-BID registration; the Oferta Permanente is a separate mechanism with its own pages.
- **BOEM / BLM.** BOEM Data Center offers ASCII, PDF, shapefile and geodatabase downloads with a disclaimer to read first; the ArcGIS REST listing at gis.boem.gov sits behind a DOI warning banner that a scripted fetch does not pass; "Active Lease Polygons" updated 1 Oct 2026, most other layers 11 Feb 2025. BLM's NFLSS rendered nothing without JavaScript; lease-sale parcel lists and shapefiles exist per sale but were not read.
- **Guyana, Namibia, Mexico.** petroleum.gov.gy publishes the Block S4 and S7 petroleum agreements, the Liza production licence, a well-activities database and production charts, with no licence statement; the 2022 round terms are known from press, not from a regulator dataset. Namibia's MME host did not resolve from this session; the April 2025 Landfolio cadastre portal has a public map but no stated download. CNH's `hidrocarburos.gob.mx` hosts returned 522/523 on the day; Rondas México describes contracts but exposes no open dataset on its front page; CNIH data is under user licences. These three need a manual seed in `country_sources` and the pack must say "no open regulator feed".
- **Contracts and EITI.** ResourceContracts is CC BY-SA 4.0: anything the Vault derives from it (a fiscal table, a clause summary) must carry the same licence, so such items stay public and are never merged into a confidential record; the API has no documented key or rate limit, so the fetcher must be polite (one request a second, cached by contract id). EITI recommends CC BY 4.0 and publishes an API, but the API page returned only the site shell; country summary data as Excel and bulk CSV is the dependable route.
- **Paid platforms.** Wood Mackenzie Lens Direct, Rystad Spektra (API and MCP), GlobalData's blocks API (£1,000) and Welligence are subscription only; their pages were read for practice, not for data. Lexology Panoramic is subscription; individual chapters are republished by contributing firms (VdA's Angola chapter was read) and may be cited as such.
- **The stack.** Citation enforcement means a pack section without a reachable source is rendered empty with a "not found" line, never filled from the model's memory. Pack runs are jobs under the existing 15-minute and £3 caps; regulator fetches are cheap but the contract text is long, so `readFacts` must be capped per contract. All fetchers run on the Vault service (no provider or regulator calls from the browser). Everything the pack files is a public item or asset, so `isVisible` is unaffected; the firm's own questions to data rooms are project-scoped. Hide, never delete: a superseded pack section is superseded, not overwritten.
