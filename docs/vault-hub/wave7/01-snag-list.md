# Wave 7 · Hub snag list

Debugging pass over every Hub screen, the tool pages the Hub opens and the Vault routes they call. Everything below was observed on a locally running Vault (embedded Postgres, filesystem storage, no LLM / World Monitor / GeoNames keys, signed in as `chris` partner and separately as `ana.perez` associate) driven through a static proxy at `/hub/` with Playwright Chromium at 1440×900, 1024×768 and 820×1180, with seeded data: five projects in CO, PE, KZ and two unplaced, four organisations, three contacts, eight runs (two vintages, one superseded, one on an older breaking version), eight documents (PDF, XLSX, PNG, email, letter, basis note, uploads through the Hub), a dispatch, two lessons and two attached fields. Where a finding is about code it carries `file:line`; where it is about what the page did it carries a screenshot under `evidence/snag-*.png`.

Baselines run first, both green:

| Suite | Result |
|---|---|
| `cd vault && npm test` | 473 tests · 472 pass · 0 fail · 1 skipped (173 s) |
| `npx playwright test test/e2e/hub-*.spec.mjs` | 146 passed · 0 failed (2.4 min) |

The suites pass because they mock the API shapes they expect; most of the snags below sit between the real API and the page, or in data the suites never seed (a second project, firm-tagged documents, a project with no client contacts, a research run with no provider).

Severity: **blocker** (an engineer cannot do the task), **major** (wrong result or a dead end), **minor** (works, but misleads or costs time), **cosmetic**, **remove** (not useful to an ATC petroleum engineer or duplicates something). Effort S = under half a day, M = one to three days, L = more.

1. **S13** Opportunity Register and APEX Reservoir 3D open a sign-in wall from the project toolbar: the two tools an engineer reaches for first do not open.

3. **S30** Find returns the same irrelevant document for any query in any scope; nobody will trust it after the second search.

5. **S32** A found document does not open; the engineer has to locate it again in the timeline.
6. **S2** The My projects cards are blank on every project.
7. **S3** Queues, Analogues and Cost are missing from the sidebar on the pages people start from.
8. **S17** Automatic research buries a project's eight records under 22 marginal papers in the timeline and lineage.
9. **S14** Restoring an archived project changes its status to Prospect.

## How this was run

Vault: `cd vault && DEV_USER_EMAIL=chris@alpha-technical-centre.com PORT=8787 VAULT_STORAGE=filesystem VAULT_STORAGE_DIR=<scratch> npx tsx src/server.ts` (a second instance on 8788 as `ana.perez@…` for the associate checks). A 40-line Node proxy served the repo root on 8020/8021 and forwarded `/api`, `/mcp`, `/oauth`, `/.well-known`. Seeding through the API only (`POST /api/organisations`, `/contacts`, `/projects`, `/runs`, `/items` multipart, `/ingest/upload`, `/dispatches`, `/lessons`, `/projects/:id/assets`, `/analogues/emit/:run`). Pages driven with Playwright Chromium; every console error, page error and non-2xx response captured; external CDN and font failures (sandbox has no outbound TLS) were discounted except where the page had no fallback (S42). Servers were stopped after the run. No repository file other than this one and `evidence/snag-*.png` was changed.
