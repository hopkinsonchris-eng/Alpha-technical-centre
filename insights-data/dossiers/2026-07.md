# Radar dossier, July 2026 edition

**Window searched:** June and July 2026. First edition, so the window is
widened to two months; there is no prior coverage to dedupe against and the
ledger was empty.

**Run date:** 30 July 2026.

**Headline constraint on this edition:** OnePetro returns HTTP 403 to automated
fetching, so SPE paper abstracts could not be read directly. JPT technology-focus
synopses are member-restricted and truncate after the introduction. Where a
result sits behind that paywall, this edition says so and reports only what is
publicly visible. Two candidates were dropped outright because nothing readable
could be reached. **With an SPE membership login available to the run, this
edition would have been materially deeper.**

No region exceeds one sixth of the edition, so the balance rule holds. But the
absolute coverage is thin: the **Middle East, Asia-Pacific and Africa produced
nothing at all** this month. Africa surfaced only as an ExxonMobil FID, which was
rejected as not technology. This is a search failure. Those regions publish
through ADIPEC, IPTC and APOGCE proceedings, which sit on OnePetro behind the
same 403 that blocked everything else. The August edition needs a route into
those proceedings, either through member access or through the conference
programme pages directly.
